# Garage Manager

A simple vehicle maintenance tracker built for everyday drivers.

## Features

- Add and delete vehicles
- Track current mileage
- Add vehicle-specific maintenance records
- View maintenance history
- Track upcoming service dates and mileage
- LocalStorage persistence

## Built With

- HTML
- CSS
- JavaScript
- LocalStorage
